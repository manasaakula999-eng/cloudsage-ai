# Contributing to CloudSage AI

Thanks for your interest in contributing!

## Getting started
1. Fork the repository.
2. Create a branch: `git checkout -b feature/your-change`.
3. Run the backend and frontend locally using the README.
4. Add or update tests where appropriate.
5. Submit a pull request describing the problem, the solution, and how you tested it.

## Good first issues
- Improve keyboard accessibility and screen-reader labels.
- Add tests for empty PDFs and scanned PDFs.
- Add a configurable maximum upload size.
- Improve retrieval ranking and add evaluation examples.
- Add a Docker Compose development setup.
- Add a Firebase Authentication integration.

## Pull request checklist
- [ ] The change has a clear purpose.
- [ ] Tests pass, or any limitation is explained.
- [ ] Documentation is updated.
- [ ] No API keys, secrets, private documents, or local environment files are committed.

Be respectful and constructive in issues and reviews.
